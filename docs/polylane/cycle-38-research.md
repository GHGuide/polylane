# Cycle 38 research application

No new external search was required during implementation. The cycle translated the
frozen Cycle 37 research into local Bash 3.2 + jq contracts: real rendered evidence,
non-compensatory task and accessibility vetoes, held-out calibration, independent
mirrored comparisons, uncertainty, truthful machine-versus-human labels, and bounded
repair. Fixtures were used only to exercise interfaces and rejection behavior; they
do not count as benchmark observations.
