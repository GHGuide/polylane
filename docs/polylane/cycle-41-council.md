The council elected a dependency-safe contract cycle as the highest-value continuation.
Starting the expensive source/judge campaign now would spend against incompatible
producer/consumer schemas, a selector that needs all 3,159 image hashes, an unbound
prompt-to-request chain, ambiguous judge configuration/session identities, inconsistent
UI v2 cardinalities, and a runner that can mutate a valid handoff. Cycle 42A therefore
freezes one hashed v3 trust boundary in four independent lanes: execution identities,
transitive evidence/claims/statistics, source/calibration/resource policy, and persisted
finalization plus autonomous/external routing. A deferred integrator alone may create
the aggregate lock and claim registry after all four contracts pass adversarial tests.

The council retained the external source/provider goal but removed it from autonomous
repair routing. It rejected full-source download, fixture upgrading, provider-label
independence, mirrored-sample inflation, post-result threshold changes, global prompt
line deduplication, and any human-certification wording. The strongest future machine
claim remains `HUMAN_CALIBRATED_MACHINE` with `human_certified:false`.
