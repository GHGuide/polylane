# Cycle 15 skill suggestions

All recommended skills are already installed, so this cycle needs no network install
or untrusted acquisition.

- `skill-creator` — tighten broad triggering metadata and move domain variants into
  one-level progressive-disclosure references.
- `product-management:write-spec` — express non-software outcomes as deliverables,
  constraints, decisions, and measurable acceptance rather than feature lists.
- `engineering:testing-strategy` — design cross-domain evidence and adversarial
  fixtures, especially for claims that cannot be reduced to a unit test.
- `product-management:product-brainstorming` — challenge the project-kind router
  against custom and mixed projects without forcing an app shape.
- `superpowers:test-driven-development` — add the non-app contract corpus before
  changing the skill language.
- `superpowers:verification-before-completion` — prevent prose-only claims that a
  trading strategy, operational process, or research conclusion is “done.”

Selection: the two contract-oriented skills arm `domain-contract`; the two
testing/planning skills arm `project-runtime`; both lanes receive the installed
test-driven and verification base.
