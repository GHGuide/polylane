# Cycle 16 questions

## Resolved autonomously

- **Should a generic follow-up interrupt every promoted cycle?** No. `after-cycle`
  records `none` and continues unless deliverables, evidence, risk, or next focus
  materially changed.
- **Can a textual skill match be armed?** No. A candidate needs current-fingerprint,
  lane-shaped benchmark evidence and `safe_to_apply: true`; **None** is explicit.
- **Can unknown telemetry be optimized?** No. The accepted receipt preserves unknown
  measurements and never fabricates an optimizer row.

## Open only when material

- Which profile-specific source receipt, review, or external evidence would change the
  next deliverable or risk boundary?
- Does an operator need a real 6-, 12-, or 24-hour isolated soak after accelerated
  fault evidence is accepted? That elapsed-time proof is optional and never blocks CI.
- Is a consequential action actually requested? If so, prepare its simulation receipt
  and ask for approval bound to the exact hash; do not perform the action.
