# 005 — Evidence-first domain autonomy

Status: accepted in cycle 16.

Polylane will represent domain execution as declarative adapters and graders rather than
embedding industry prose in worker prompts. Real-source receipts, profile-aware grading,
accepted-outcome learning, benchmark-gated skills, and resumable fault tests become shared
runtime contracts. Optional live canaries may refresh evidence, but deterministic cached
snapshots remain the completion path.

Consequential actions stay two-phase: prepare and simulate an exact, hashed impact preview;
execute only after explicit approval for that receipt. No learning or economy policy may
weaken this boundary.
