# Cycle 16 council — evidence-driven domain autonomy

## Decision

Adopt the domain-runtime, trial, soak, learning, and skill-benchmark mechanisms as
runner-wired evidence gates. The council accepts only deterministic source-pinned
trials, executable profile bundles, accepted-outcome evidence, and explicit action
receipts as automation evidence. It does not convert optional live canaries, wall-clock
soaks, or external action authority into a pass.

## Integration rulings

- Keep profile-grader registration in per-run `.polylane/` scratch; commit only the
  final bundle, grade, and integration evidence from the verified integrator branch.
- Keep lane topology/context recommendations visible but planner-owned. The runner may
  apply only one measured available model or effort change after safety clamps.
- Reject unbenchmarked catalog candidates at the existing scout arming seam.
- Preserve the frozen `m12.4`/`c28` external visual corpus as unrelated external
  evidence; it is neither a Cycle-16 defect nor a reason to weaken acceptance.

## Verdict posture

The local evidence may reach `READY-FOR-HOST-GATE` only after focused checks, provider
parity, installer smoke, ShellCheck, marker/profile validation, and seam scan are fresh.
The coordinator alone runs the terminal suite and any permitted rehearsal; no local
simulation is reported as that host result.
