# Cycle 12 research

The cycle used the user-approved visual strategy: study 3–5 relevant products and one
deliberately different wildcard, extract principles rather than layouts, synthesize three
directions, and let an independent council lock one. The implementation research focused on
the failure modes that made prior generated sites look synthetic: single-source imitation,
generic gradients and cards, default typography, weak state coverage, non-image “screenshot”
evidence, and self-authored quality claims. It also established that a remote skill is supply
chain code, so usefulness is insufficient without provenance, permission/injection audit,
isolated comparative evidence, an immutable content identity, and rollback.

The production run itself supplied the strongest runtime evidence. The initial strict graph
fixture exceeded its frozen time budget despite functional correctness; profiling found an
immutable-map Kahn traversal doing avoidable work for compiler-ordered graphs. A linear rank
fast path fixed the measured bottleneck while preserving the general Kahn fallback.
