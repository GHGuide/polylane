# Cycle 15 integration — domain-general project execution

The current integration merges the domain-contract and project-runtime tips into one
workflow: discovery writes matching `PROJECT_PROFILE.md` and `PROJECT_PROFILE.json`,
the deterministic gate validates both before decomposition, and planning derives owned
repository artifacts, evidence, skills, and safety boundaries from the selected profile.

The corpus covers software, trading strategy research, literature review, incident
response, content, data, and mixed/custom outcomes. Trading remains research-first and
rejects autonomous live execution; custom work is admitted by explicit deliverables and
evidence rather than an industry allowlist. UI Visual Intelligence remains conditional on
a user-facing UI, while its safe admission, design lock, visual/copy specificity, blind
comparison, repair cap, and certification obligations remain intact. See [integration verification](../verify-integration.md) and
[parallel status](../parallel-status.md) for current-run commands, counts, package proof,
and the remaining external visual-evidence boundary.
