# Cycle 16 per-lane skill suggestions

All selected skills are already installed. No external skill is auto-installed or armed.
Each builder receives two stable execution skills and two lane-specific skills; the
integrator receives only its fixed review kit.

## `domain-runtime`

- `engineering:architecture` — shape the adapter and profile contracts without coupling
  them to one domain.
- `superpowers:test-driven-development` — freeze behavior before implementing the helpers.
- `operations:risk-assessment` — classify side effects and approval boundaries.
- `deep-research` — preserve source provenance and evidence traceability.

## `learning-economy`

- `engineering:testing-strategy` — design deterministic recommendation and confidence tests.
- `superpowers:test-driven-development` — prevent metric changes from becoming ungraded heuristics.
- `data-analytics:product-business-analysis` — define accepted progress and efficiency metrics.
- `operations:process-optimization` — turn historical outcomes into bounded policy changes.

## `trials-soak`

- `engineering:testing-strategy` — separate deterministic fast tests from optional live trials.
- `superpowers:systematic-debugging` — make injected failures produce diagnostic evidence.
- `engineering:incident-response` — model resume, recovery, and fault receipts.
- `operations:risk-assessment` — keep canaries and fault injection safe and scoped.

## Integrator

Use the installed verification, code-review, and Ponytail review skills already mandated
by the integration prompt. The integrator is intentionally not skill-scouted.
