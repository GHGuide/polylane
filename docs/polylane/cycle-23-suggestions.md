# Cycle 23 per-lane skill suggestions

The scout matched installed skills to each lane's concrete activity before prompt
generation.  This is a frozen certification, so no GitHub search or installation is
justified: an uninstalled skill would enlarge the trusted surface without improving the
required evidence.  Autonomous mode selects the installed recommended defaults below.

## `terminal-fixture-audit`

- **Selected — `superpowers:systematic-debugging`:** reconstruct both failures from the
  terminal transcript, environment boundary, manifest, source, and red-first tests.
- **Selected — `superpowers:verification-before-completion`:** require fresh focused
  output, exact commit provenance, scoped evidence, and a clean committed DONE state.
- **Not selected — `superpowers:test-driven-development`:** implementation and red-first
  regressions already exist; this lane independently grades rather than edits them.
- **Not selected — `engineering:testing-strategy`:** broader redesign would weaken the
  frozen trial and provide no additional terminal evidence.

## `integrator`

- **Selected — `engineering:code-review`:** review fixture hermeticity, ownership parity,
  exact-tip provenance, and fail-closed behavior independently.
- **Selected — `ponytail:ponytail-review`:** catch duplicated or overbuilt certification
  paths while preserving the one-gate contract.
- **Selected — `superpowers:verification-before-completion`:** issue READY only from
  reproducible focused/static evidence and leave terminal proof to the coordinator.
- **Not selected — `superpowers:systematic-debugging`:** the builder owns causal
  reconstruction; the integrator's separate role is adversarial review and synthesis.

Every selected skill is delivered by exact trusted path and fingerprint, read once, and
graded from observable `SKILL-EVIDENCE` rather than a claimed invocation.
