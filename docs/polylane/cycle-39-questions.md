# Cycle 39 emergent questions

No user decision is required before the next autonomous cycle. These questions can be
answered by frozen evidence and become Cycle 40's implementation targets:

1. Can the three released CC0 Miniukovich–Figl domains be sampled reproducibly through
   a real browser session, with source metadata, raw/aggregate labels, image bytes,
   licences, and checksums bound into one corpus receipt?
2. Which independently versioned Claude and Codex judge configurations clear the same
   unseen 24-pair human-labelled holdout, side-bias, and mirror-consistency gates?
3. Can raw CLI responses, image orientations, capture manifests, pointwise records,
   and independence attestations produce a non-fixture ballot-v2 receipt that the
   certificate compiler recomputes rather than trusts?
4. Can Playwright, PNG decoding, task replay, state coverage, and accessibility adapters
   execute against offline pages with exact versions and fail closed when unavailable?
5. Can twenty varied briefs, the pre-visual baseline revision, the current subject
   revision, prompt contracts, repair caps, and analysis thresholds all be frozen before
   the first benchmark result is observed?
6. If a calibrated configuration fails or the current workflow loses, can the loop
   preserve the incumbent and open a new preregistered repair cycle without changing the
   original study thresholds?
